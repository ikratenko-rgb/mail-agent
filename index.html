Почтовый
агент

Система автоматической обработки входящей почты. Собирает письма со всех ящиков, формирует дайджест и доставляет в Telegram — без доступа к оригинальным ящикам.

Как это работает · 6 шагов

ШАГ 01
Пересылка
Письмо приходит на ящик-донор и автоматически пересылается в хаб. Настройка разовая, встроена в Gmail.
ШАГ 02
Триггер
GAS запускается по расписанию (крон) или вручную по команде. Собирает все непрочитанные цепочки.
ШАГ 03
Обработка
Скрипт извлекает текст, ищет ссылки на отписку (List-Unsubscribe), формирует JSON-пакет.
ШАГ 04
Отправка на сервер
POST-запрос с секретным токеном. Запросы без токена отбиваются — защита от спама.
ШАГ 05
Доставка
Сервер форматирует сообщение и отправляет в Telegram. VIP-отправители — мгновенный алерт.
ШАГ 06
Маркировка
Обработанные письма помечаются PROCESSED. Повторной отправки не будет — идемпотентность гарантирована.

Безопасность

Принцип делегирования через пересылку
✓ Пароли от оригинальных ящиков нигде не вводятся и не хранятся
✓ Скрипт физически не может прочитать или сломать оригинальный ящик
✓ Работает только со слепками писем в изолированной «песочнице» хаба
✓ API защищён секретным токеном в заголовке запроса (x-hub-token)
✓ Всё работает в облаке Google и DigitalOcean — 24/7 без вмешательства

Возможности

Крон-дайджест MVP
Автоматическая отправка сводки по расписанию. Настраиваемый интервал.
Дайджест по запросу MVP
Команда в Telegram — получаешь сводку прямо сейчас, в любое время.
VIP-алерты MVP
Список важных отправителей. Их письма приходят мгновенно, не ждут крона.
Retry-логика MVP
Если сервер упал, письмо помечается API_ERROR и повторяется при следующем запуске.
Фильтры по ящикам Позже

Фильтры по времени Позже
Собирать письма только за определённый период. Кастомные временные окна.
Кнопки отписки Позже
Автоматически извлекать ссылки List-Unsubscribe и давать кнопку прямо в Telegram.
